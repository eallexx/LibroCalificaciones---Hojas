# Laboratorio 2 - Libreta de calificaciones - contador/Valor centinela

2 septiembre de 2026

## Contenido del repositorio

Este proyecto consiste en un programa que calcula el promedio de calificaciones de un curso.
El programa utiliza una clase llamada LibroCalificaciones que contiene métodos para mostrar un mensaje de bienvenida y determinar el promedio
de las calificaciones introducidas por el usuario. El programa principalcrea un objeto de la clase LibroCalificaciones, muestra el mensaje de bienvenida
y luego solicita al usuario que ingrese 10 calificaciones para calcular y mostrar el promedio.

Además, se usa una segunda clase llamada LibroCalificaciones1 que hace uso de un valor centinela para permitir al usuario ingresar un número indefinido de calificaciones hasta que decida salir
ingresando -1.

## Tecnologías utilizadas
C#

Visual Studio
